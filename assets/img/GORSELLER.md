# Görseller

Sayfa, aşağıdaki dosyalar bu klasörde varsa onları otomatik gösterir; yoksa CSS ile çizilmiş mockup görünür.
Dosya adını birebir kullanın (WebP önerilir; farklı format kullanırsanız `index.html` / `assets/js/main.js` içindeki yolları güncelleyin).

| Dosya | Nerede | Önerilen boyut | İçerik |
|---|---|---|---|
| ekran-sport.webp  | Tema galerisi → Sportsbook   | 1600×900 | Sportsbook arayüzü (maç listesi, oranlar, kupon) |
| ekran-casino.webp | Tema galerisi → Casino lobisi | 1600×900 | Casino lobisi (oyun kutucukları, banner) |
| ekran-live.webp   | Tema galerisi → Canlı casino  | 1600×900 | Canlı casino lobisi (krupiyeli masalar) |
| panel-admin.webp     | Operatör araçları → Admin     | 1600×1000 | Admin panel dashboard |
| panel-affiliate.webp | Operatör araçları → Affiliate | 1600×1000 | Affiliate paneli |
| panel-dealer.webp    | Operatör araçları → Bayi      | 1600×1000 | Bayi paneli |
| panel-bonus.webp     | Operatör araçları → Bonus     | 1600×1000 | Bonus & kampanya ekranı |
| panel-report.webp    | Operatör araçları → Raporlama | 1600×1000 | Rapor / grafik ekranı |

Not: Görsel yüklendiğinde tema renk seçicileri o ekranda görselin üzerine etki etmez (yalnızca mockup'ı boyar).
